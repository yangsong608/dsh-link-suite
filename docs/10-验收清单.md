# DSH Link · 验收清单（M0 + M1）

> 这份清单的存在理由：**34 项自动化测试证明的是"零件正确"，不是"链路可用"。**
> 分析报告里最刺眼的一条是"三个子工程的测试全绿，但端到端一次都没跑通"。
> 下面每一条都必须真机走一遍，并把结果贴进对应 PR。

## 0. 准备

```bash
# 协议 → 插件 → App 的顺序不能反（插件读协议的 dist）
cd shared/protocol && npm install && npm test      # 24 passed
cd ../../plugin && npm install && npm test          # 73 passed
cd ../app && npm install && npm run typecheck       # 0 error

# 装进 desktop profile
DSH="/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh"
cd .. && "$DSH" plugin --profile desktop add "dsh-link@link:$PWD/plugin"
```

装完重启 dsh，日志应出现：

```
[dsh-link] gateway 监听 <lan-ip>:7443（明文 WS）
[dsh-link] lock.enabled=true 但未设置密码，锁屏未武装。打开 Web 界面设置密码...
```

## 5. 已知限制（不算失败）

- **没有 E2E**：局域网内可被嗅探。不要暴露公网、不要在开放 WiFi 下配对。
- **没有中继**：跨网络连不上（只能同局域网或 Tailscale）。
- **没有恢复码**：忘记密码只能删 `lock.json`。
- **没有 WebAuthn**：只能输密码。
- 文件/仓库/插件/终端页仍是 `notImplemented`。
- `gateway.via: 'dsh-web'` 只有配置位，upgrade 挂载未落地。
